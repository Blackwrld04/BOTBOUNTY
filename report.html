Item / Finding Status Engineering Resolution
1. Frontend Funding & Real Payout
Placeholder "0xarc" text & DB-only payouts		 Resolved • Replaced all legacy "0xarc" references and direct-transfer instructions in CreateBountyModal.jsx with a 1-click Web3 wallet funding flow directly calling createBounty(...) with on-chain explorer receipts.

2. Submission Ownership & Session Auth
Spoofable wallet/email parameters		 Resolved • Stripped spoofable query parameters (?email=, ?wallet=) and headers (x-user-email, x-wallet-address). Reads return empty ([]) to unauthenticated callers; solvers see only their own submissions; admins see all.
• Submission edits require authenticated session tokens (401) and strict ownership verification (403 if editing another solver's work). Body spoofing is completely ignored.
• Enforced anti-self-solve lockout preventing bounty maintainers from solving their own bounties. Added 12 automated negative tests (48/48 backend tests passing).
3. Privacy & Blind Submissions
Public PR URLs in storage/events		 Resolved • Clarified privacy wording across UI and documentation: portal deliverables are confidential between solver and maintainer during review to prevent competitor sniping, while final settlement details and recipient addresses are public on-chain for DAO auditability.
• Implemented cryptographic blind commit-reveal escrow in BotBountyEscrow.sol (submitSolutionCommitment / releaseBountyWithProof) with keccak256(solver, prUrl, salt) so deliverable URLs are never published on-chain during review.
4. Supported Tokens & Policies
Token validation, timeout & rejection		 Resolved • Formally configured native $BOT (address(0)) and Bridged USDT (0x75edC9335175Fc0552D51D48439F229c10420fe3).
• Added settlementToken.code.length > 0 check to reject invalid/EOA token addresses.
• Protected against fee-on-transfer discrepancies via balance delta checks (balanceAfter - balanceBefore == amount).
• Added anti-junk URL guard (length >= 10), 1–30 day maintainer review period, rejection with on-chain feedback reasons, timeout auto-claim, and maintainer deadline refund.
